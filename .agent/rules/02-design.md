# Règles permanentes - Design

- Palette noir, blanc, gris clair ; accents discrets uniquement pour don, urgence, certification.
- Aucune icône décorative devant les titres, aucun emoji dans l'interface, aucun dégradé criard ni style "template IA".
- Mobile-first, accessibilité WCAG 2.2 AA, respect de prefers-reduced-motion.
- 3D uniquement sur les pages et usages prévus au document 09, chargée à la demande, avec repli statique.
- Aucune valeur de couleur ou d'espacement en dur : utiliser les tokens.
